## 0. 全社共通の判断基盤（過去のやり取りより）

`CLAUDE.md` および `docs/引き継ぎ_不動産投資現況サマリー.md` に蓄積済みの判断軸：

| 指標 | 基準 |
|------|------|
| 返済比率 | 返済月額 ÷ 現況賃料月額 ≦ **50%**（理想40%台） |
| 資産性 | 積算評価が物件価格の **50%以上** |
| 諸経費 | 物件価格の **8%** で試算 |
| 収益性スコア | (50 − 築年数) ＋ 利回り% |
| 融資方針 | フルローン／オーバーローン優先、自己資金850万円以下に温存 |
| 立地条件 | 市街化区域／再建築可／接道4m以上／ハザード非該当 |

過去の融資実例（55件, 2025年12月〜2026年5月）では、オリックス銀行・山陰合同銀行・静岡銀行・滋賀銀行が100%融資（金利2.6〜3.8%）の実績あり。この基盤に対し、以下の最新情報で各部署の判断精度を上げる。

## 1. エアリス — 経理・税務

### 保有知識（既存）
- 法人（株式会社TK）と個人事業（TK不動産）の二重運用、諸経費8%試算

### 2026年の最新知見（Web調査）
- **令和8年度（2026年度）税制改正大綱** — インボイス制度の経過措置が変更：
  - 2割特例は2026年9月30日で終了。個人事業主のみ、2026年10月〜2028年9月の2年間限定で「3割特例」が新設（**法人は対象外**）
  - 2026年10月以降、免税事業者からの仕入れに対する買い手側の仕入税額控除が縮小（現行の経過措置がさらに絞られる）→ 事業用テナント（店舗・駐車場等）がいる物件はテナント側のコスト増につながり、賃料交渉の火種になり得る
  - **居住用賃貸（アパート・マンション）はもともと非課税取引のため、インボイスの直接影響は限定的**
- **相続税評価ルールの見直し**（令和9年1月1日以後の相続から適用見込み）：相続開始前**5年以内**に取得した賃貸用不動産は、路線価等の通常評価ではなく「市場価格（通常の取引価額）」で評価 → 直前購入による評価圧縮スキームが事実上封じられる方向

### アクションポイント
1. 法人（株式会社TK）は3割特例の対象外である点を踏まえ、消費税納税シミュレーションを2026年10月改定で再実施
2. 居住用物件中心のポートフォリオはインボイス影響が小さいことを確認済みとして経営会議に報告
3. 相続税評価見直しを見据え、新規取得物件は「節税目的の直前購入」ではなく実需・収益性ベースでの取得判断に統一

## 2. ザックス — 営業・賃貸管理（客付け・空室対策）

### 2026年の最新知見（Web調査）
- 空室対策は「感覚」から「データ」への移行が進む — 反響データ・市場動向分析による課題の可視化が業界標準に
- **高齢者見守りサービス**の導入が急拡大（累計契約件数が2026年2月時点で前年同月比5倍）
- **セーフティネット住宅**（高齢者・低所得者・障害者等の入居を拒まない登録住宅）の登録戸数が2025年12月時点で95万戸超 — 空室対策の選択肢として拡大中
- 人気設備: Wi-Fi無料、宅配ボックス、浴室換気乾燥機、TVモニター付きインターホン、防犯カメラ、敷地内夜間照明
- ペット可物件は「家賃・初期費用」の柔軟性が最大の課題・差別化ポイント

### アクションポイント
1. 保有・検討物件について、Wi-Fi無料化／宅配ボックス設置のコスト対効果を試算
2. 空室が続く物件はセーフティネット住宅登録・高齢者見守りサービス導入を検討
3. ペット可物件化の是非を家賃設定とセットで再検討

## 3. ユフィ — 物件調達

### 2026年1〜3月期 市場データ（Web調査・収益物件市場動向レポート系）
| 区分 | 表面利回り | 価格 |
|------|-----------|------|
| 全国平均 | 8.06% | 9,027万円 |
| 一都三県平均 | 6.89% | 1億263万円 |
| 東京23区 | 5.65% | 1億4,325万円 |

- 前年同期比：価格は全国+13.21%、一都三県は利回り-0.36pt、東京23区は利回り-0.26pt — **価格上昇・利回り低下**の傾向が強まっている
- 築年数別利回り（全国）：築10年未満6.02% ／ 築10年以上6.91% ／ 築20年以上9.51%
- 地域別利回り：首都圏6.13%／関西6.86%／東海9.08%／北海道13.02%／東北12.84%／中国四国15.03%／九州沖縄8.90%
- 実質利回りは表面から2〜4pt程度目減りするため、**4〜7%が現実的な運用ライン**という試算

### 既存注目物件との照合
- 狭山市軽鉄AP（利回り9.71%）、新座市RC（9.02%）は、いずれも一都三県平均6.89%を大きく上回る好条件。表面利回りが高い分、実質利回りでも4〜7%ラインを十分クリアする見込み
- 東北・北海道・中国四国など地方エリアは表面利回り12〜15%台と高水準 — 自己資金温存戦略（フルローン狙い）との相性を検討する価値あり
- 東京23区・首都圏都心部は利回り低下が続いており、現行の返済比率50%基準を満たしにくい可能性が高いため、当面は様子見が妥当

### アクションポイント
1. 物件評価一覧（フルローン物件一覧v37以降）に「地域別平均利回りとの乖離」列を追加し、割安度を可視化
2. 地方高利回りエリア（東北・北海道・中国四国）の情報収集を強化

## 4. ケットシー — 融資調達

### 2026年の最新知見（Web調査）
- **金利相場（2026年3月時点目安）**：メガバンク1.5〜2.5%／地方銀行2.0〜4.5%／ノンバンク3.0〜5.0%超
- 10年国債利回りは2026年6月時点で2.69%台と高止まり。日銀は経済・物価情勢次第でさらなる金融緩和度合いの調整（利上げ）を示唆
- **フルローンのハードルが上昇** — 多くの金融機関が物件価格の10〜20%程度の頭金を求める傾向が強まっている（以前より容易ではない）
- 金融機関の融資姿勢は「積極」と「慎重」に二極化 — 複数行への並行相談・比較が有利な条件を引き出す鍵

### 既存の融資実例（過去データ）との整合
- オリックス銀行100%・2.65%、auじぶん銀行95〜100%・2.4%、山陰合同銀行100%・2.6%、静岡銀行100%・2.6〜3.8%、滋賀銀行100%・2.6% — いずれも2026年5月時点の実例で、上記のメガバンク／地銀レンジと整合。ただし今後は頭金要求が強まる可能性があるため、実例の鮮度確認が必要

### アクションポイント
1. 打診の都度、フルローン継続可否を金融機関に確認し、10〜20%頭金要求時の代替プラン（BROZERO等の無担保ローン併用）を用意
2. 金利上昇シナリオ（+0.5〜1.0pt）での返済比率再計算をルーティン化し、50%基準にバッファを持たせる
3. 積極姿勢の金融機関リストを継続更新し、複数行同時打診を標準化

## 5. ヴィンセント — 戦略（ポートフォリオ・出口戦略）

### 2026年の最新知見（Web調査）
- **相続税評価ルールの見直し**（令和9年1月1日以後の相続に適用見込み）：相続開始前5年以内に取得した賃貸用不動産は市場価格で評価 → いわゆる「不動産による相続税圧縮」の効果が薄れる方向
- 法人化タイミングの考え方：出口戦略（売却か長期保有か）を先に決めてから法人化を判断すべき。短期売却前提の物件は個人保有のまま、法人保有を選ぶ場合は長期継続経営を前提とする
- 後継者不在の場合は信託・現金化も選択肢として検討する必要あり

### アクションポイント
1. 株式会社TK（法人）保有物件は「長期継続経営」を前提とした出口戦略（売却 or 承継）を物件ごとに明文化
2. 相続税評価見直しを踏まえ、直前購入による節税効果を狙う取得は避け、収益性・積算評価ベースの取得基準（既存の判断指標）を堅持
3. 後継者（承継）方針を経営会議で一度整理し、信託活用の要否を検討

## 6. シスネ — 法務

### 2026年の最新知見（Web調査）
- **原状回復ガイドライン（再改訂版・国交省）**：2020年民法改正で「通常損耗・経年変化は借主の原状回復義務から除外」が法定化済み。再改訂版（全173ページ）は章単位でダウンロード可能
- **宅地造成等規制法 → 「宅地造成及び特定盛土等規制法」に改称**（2023年施行、2024年以降運用強化）：土地の用途を問わず危険な盛土等を全国一律基準で包括的に規制
- 宅建業法関連：帳簿の電子計算機記録による代替（紙面保存義務の緩和）が明確化

### アクションポイント
1. 賃貸借契約書・退去精算のひな形が最新の原状回復ガイドラインに準拠しているか点検
2. 検討中・保有中物件について、盛土規制区域の該当有無をハザードマップ・自治体公表資料で確認（既存の立地判断基準「ハザード非該当」に統合）
3. 帳簿の電子保存移行を経理（エアリス）と連携して検討
