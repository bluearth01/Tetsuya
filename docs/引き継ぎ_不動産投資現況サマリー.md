## 6. 投資戦略・方針

| 項目 | 方針 |
|------|------|
| 融資方針 | フルローン（100%）またはオーバーローン優先 |
| 自己資金 | 850万以下に抑える（諸経費は自己資金） |
| 返済比率目標 | **50%以下**（理想は40%台） |
| 収益性判断 | スコア = (50-築年数) + 利回り% |
| 資産性判断 | 積算評価額が物件価格の50%以上 |
| 定性判断 | 市街化区域・再建築可・接道4m以上・ハザード外 |
