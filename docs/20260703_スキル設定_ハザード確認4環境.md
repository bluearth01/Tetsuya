# スキル設定手順 — ハザード確認スキル（hazard-check）を4環境で使う

- **日付:** 2026-07-03
- **作成者:** クロコ（参謀AI / Claude Code on the web）
- **スキル本体:** リポジトリ `.claude/skills/hazard-check/`（SKILL.md ＋ 判定スクリプト）
- **配布用zip:** `docs/20260703_スキル配布_ハザード確認.zip`

## スキルの機能

住所を伝えるだけで、国交省「重ねるハザードマップ」の配信データを座標照会し、
洪水（想定最大/計画規模）・浸水継続時間・家屋倒壊等氾濫想定区域・土砂災害3区分・津波・高潮の
該当/非該当、最寄り区域までの距離・方角、標高を自動判定します。

使用例: 「宇都宮市鐺山町2009-5のハザードを確認して」→ 総合判定＋根拠URL付きの報告

## 環境別の設定

### ① Claude Code on the web（本リポジトリ）— 設定済み ✅

`.claude/skills/hazard-check/` をコミット済み。セッション開始時に自動で読み込まれ、
「ハザード確認して」の依頼で自動発動します（`/hazard-check` でも起動可）。

### ② Claude Code CLI（ノートPC）— リポジトリをcloneすれば自動で有効 ✅

このリポジトリ（bluearth01/Tetsuya）を clone または pull すれば、
①と同じく `.claude/skills/` が自動で読み込まれます。追加設定は不要です。

### ③ claude.ai Webチャット（ノートPC）— zipアップロードが必要 🔧

1. claude.ai → **設定（Settings）→ 機能（Capabilities）→ スキル（Skills）** を開く
2. **「スキルをアップロード」** から `20260703_スキル配布_ハザード確認.zip` をアップロード
3. スキル一覧に「hazard-check」が表示されれば完了

※ claude.ai のコード実行環境は外部ネットワークが制限される場合があります。
その場合スキルは自動で「手順B（手動照会）」にフォールバックし、
重ねるハザードマップのURL提示＋Web検索での確認に切り替わります。

### ④ iPhoneアプリ・デスクトップアプリ — ③と同時に有効化 ✅

スキルはアカウント単位で保存されるため、③でアップロードすれば
同じアカウントの iPhone アプリ・デスクトップアプリのチャットでもそのまま使えます。
端末ごとの追加設定は不要です。
