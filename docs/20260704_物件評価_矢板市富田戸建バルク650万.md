- 固定資産税評価合計 = 811.8万円 → **積算率 124.9%**（811.8万 ÷ 650万）✅
- 土地のみでも 586.9万円 → **90.3%** ✅（社内基準50%を大幅クリア、土地値以下での取得）

**固都税の概算（「調査中」だった項目）**
- 土地は住宅用地特例（5戸×200㎡＝1,000㎡枠内で全て小規模住宅用地1/6）→ 課税標準約97.8万円 → 固定資産税約1.4万円/年

- **合計概算 約4.5〜5.5万円/年**（都市計画税の有無は矢板市の課税区域要確認）→ 年収182万に対し軽微
