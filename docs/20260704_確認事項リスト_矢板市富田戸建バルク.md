# DD確認事項リスト — 矢板市富田戸建バルク（富田向原589-11・589-12）

作成: 2026-07-04 クロコ ／ 用途: 仲介への質問メール・市役所照会・現地調査のチェックリスト

## A. 仲介会社への確認（メール文例付き）

1. **建物状態**
   - 雨漏り・シロアリ・傾きの既知の不具合の有無（告知事項）
   - 屋根（亜鉛メッキ鋼板瓦棒葺）の葺き替え・塗装履歴、給排水管の更新履歴
   - 直近の修繕履歴一覧（あれば）
2. **賃貸借関係**
   - 各戸の入居年数・属性・滞納履歴、敷金の有無と承継額
   - 賃貸借契約書5戸分の写し（原本確認は契約時）
   - 管理会社の有無・管理料率、自主管理なら引継ぎ方法
3. **権利・境界**
   - 私道負担「確認中」の結論（実測図上は西側が法42条1項3号道路）
   - 境界標の現存状況（実測図あり・境界明示の可否）
   - 589番12（33.06㎡の細長地）の役割（通路・間口確保部分か）
4. **法令・税**
   - 検査済証「確認中」の結論
   - 固都税の実額（当方概算: 年4.5〜5.5万円）
   - 都市計画税の課税有無（矢板市の課税区域か）
5. **取引条件**
   - 取引態様（媒介種別）、売主の売却理由・売却希望時期
   - 指値の余地感、他の検討客の有無

## B. 矢板市役所（建築指導担当）への確認

1. 西側道路の道路種別の裏取り: **法42条1項3号道路**で相違ないか（道路台帳の閲覧）
2. **有効間口**: 実測図中1.78〜2.0m表記の狭小部が接道長に影響しないか（接道義務2m以上）
3. 5棟が1敷地扱いか各棟別敷地か（**一敷地一建物原則**との関係）、将来1棟ずつ建て替える場合の敷地分割要件
4. 第一種低層住居専用地域（建蔽40/容積60）での再建築ボリューム: 現況延床188.42㎡は容積60%（317㎡）内で問題なし
