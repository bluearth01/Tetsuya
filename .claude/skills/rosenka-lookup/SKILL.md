# 路線価調査・積算評価スキル / Rosenka Lookup

株式会社TK・TK不動産の物件調達判断用。所在地から路線価を特定し、積算評価額を算出して
「物件価格の50%以上」基準（社内判断指標）で判定する。

## 入力（社長から受け取る情報）
- 物件所在地（都道府県・市区町村・町丁目まで。地番があればなお良い）
- 土地面積（㎡）
- 建物：構造（木造/軽量鉄骨/重量鉄骨/RC）・延床面積（㎡）・築年
- 物件価格（判定用）

不足があれば推測せず社長に確認する。

## 調査手順

### Step 1: 路線価の特定
1. **国税庁 財産評価基準書（路線価図）**: https://www.rosenka.nta.go.jp/
   - 最新年分 → 都道府県 → 市区町村 → 町丁目で路線価図PDFのページ番号を特定する
2. 補助情報源: **全国地価マップ**: https://www.chikamap.jp/chikamap/Portal?mid=216
   （相続税路線価・固定資産税路線価・地価公示を横断確認できる）
3. 路線価図の数値は **千円/㎡** 単位（例: `115D` → 115,000円/㎡。末尾記号は借地権割合で自用地評価では無視）
4. 路線価が付されていない地域（倍率地域）の場合は、固定資産税評価額×評価倍率方式である旨を明示し、
   全国地価マップの固定資産税路線価または近隣公示地価×0.8で代替概算する（概算であることを必ず明記）

### Step 2: PDF読み取り（環境別フォールバック）
- **PC環境（Claude Code CLI/デスクトップ/IDE拡張）**: `curl`等でPDFを取得し、Readツールで目視読み取り
- **Claude Code on the web（クラウド版）**: Bash+curlで取得を試みる（プロキシ経由）。取得できたらReadで読み取り
- **claude.aiウェブ/iPhoneアプリ**: コード実行環境（アナリシスツール）でのダウンロードを試みる。
  不可なら **原典PDFのURLとページ番号を提示し、社長に開いて数値を読み上げていただく方式にフォールバック**
- どの環境でも、**原典URLと路線価図のページ番号の明記は必須**（社長が原典確認できることを最優先）

### Step 3: 積算評価の計算

**土地積算評価**
```
土地積算 = 路線価（円/㎡） × 土地面積（㎡）
```
（角地・二方路等は加算があるが、概算では一方路線で保守的に計算し、その旨を明記する）

**建物積算評価**
```
建物積算 = 再調達価格（円/㎡） × 延床面積（㎡） × 残存耐用年数 ÷ 法定耐用年数
```

| 構造 | 再調達価格（目安） | 法定耐用年数 |
|------|-----------------|-------------|
| 木造 | 15万円/㎡ | 22年 |
| 軽量鉄骨（3mm以下） | 15万円/㎡ | 19年 |
| 軽量鉄骨（3〜4mm） | 16万円/㎡ | 27年 |
| 重量鉄骨（4mm超） | 18万円/㎡ | 34年 |
| RC | 20万円/㎡ | 47年 |

- 耐用年数超過の建物は建物積算 = 0（土地値のみ）として評価
- 残存耐用年数 = 法定耐用年数 − 築年数（マイナスは0）

**判定**
```
積算評価合計 = 土地積算 + 建物積算
積算率 = 積算評価合計 ÷ 物件価格
```
- 社内基準: **積算率 50%以上** で資産性クリア（CLAUDE.md 判断指標に準拠）

## 出力フォーマット（結論先出し）

1. **判定サマリー**: 積算評価合計◯◯万円 / 物件価格◯◯万円 = 積算率◯◯% → 基準50%に対し ✅/❌
2. **土地**: 路線価◯◯千円/㎡ × 面積 = ◯◯万円（原典: 路線価図URL・ページ番号）
3. **建物**: 構造・築年・残存年数・計算式と結果
4. **前提と注意**: 一方路線の概算である旨、倍率地域なら代替方式の旨
5. **原典リンク一覧**（必須）: 国税庁路線価図URL（ページ番号付き）、全国地価マップURL
