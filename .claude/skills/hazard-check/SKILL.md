# ハザードマップ評価スキル（hazard-check）

住所 → 座標変換 → 国交省「重ねるハザードマップ」の配信タイルを色判定 → Excel評価表を生成する。

## 実行手順

1. **依存ライブラリ確認**（初回のみ）:
   ```bash
   pip install Pillow openpyxl
   ```

2. **スクリプト実行**（出力先は必ず作業用ディレクトリ＝スクラッチパッドにする。リポジトリ内に生成物をコミットしない）:
   ```bash
   python3 .claude/skills/hazard-check/scripts/hazard_check.py "栃木県宇都宮市〇〇町1-2-3" \
     -o <scratchpad>/YYYYMMDD_ハザード評価_対象地.xlsx
   ```
   - ファイル名は社内規定「年月日_汎用タイトル_具体的な対象」に従う（スクリプトのデフォルト名も同形式）。
   - 複数物件を一括評価する場合は住所ごとに実行し、ファイルを分ける。

3. **結果報告**（結論先出し・社内コミュニケーション規定に従う）:
   - スクリプトが標準出力するMarkdownサマリー表をそのままチャットに提示する。
   - 総合判定（○/△/×）を最初に述べる。判定基準:
     - **○** = 全ハザード非該当 → 社内基準「ハザード非該当」に適合
     - **△** = 浸水深0.5m未満、または土砂イエロー（警戒区域）該当 → 要検討
     - **×** = 浸水深0.5m以上、または土砂レッド（特別警戒区域）該当 → 基準不適合
   - 生成したxlsxを SendUserFile で社長に送付する。
   - Google Drive MCP が接続されている場合は、クロコ作業フォルダ
     （フォルダID: `1WMPAy8Vt_vx_moo74haeUfTIVnFeOLkN`）にもコピーをアップロードする。
   - 必ず「自動色判定のため、最終判断前に重ねるハザードマップの目視確認が必要」と添える
     （目視確認URLはスクリプトが出力する）。

## 確認するハザードと判定内容

| ハザード | データレイヤー | 判定内容 |
|---|---|---|
| 洪水（想定最大規模） | 01_flood_l2_shinsuishin_data | 浸水深ランク（0.5m未満〜20m以上） |
| 津波 | 04_tsunami_newlegend_data | 浸水深ランク（同上） |
| 高潮 | 03_hightide_l2_shinsuishin_data | 浸水深ランク（同上） |
| 土砂災害（土石流） | 05_dosekiryukeikaikuiki | イエロー（警戒区域）/ レッド（特別警戒区域） |
| 土砂災害（急傾斜地の崩壊） | 05_kyukeishakeikaikuiki | 同上 |
| 土砂災害（地すべり） | 05_jisuberikeikaikuiki | 同上 |

各ハザードとも「地点判定」に加え「周辺約50mの最大判定」を併記する（ジオコーディングの座標誤差・敷地の広がり対策）。

## ネットワークが遮断されている場合のフォールバック

このスキルは `msearch.gsi.go.jp`（住所検索）と `disaportaldata.gsi.go.jp`（タイル配信）への
HTTPSアクセスが必要。実行環境のネットワークポリシーで遮断されている場合（403/CONNECT失敗）:

1. その旨を社長に報告し、以下を提示する:
   - 手動確認用URL: `https://disaportal.gsi.go.jp/maps/?ll=<緯度>,<経度>&z=16&base=pale`
     （座標不明の場合は https://disaportal.gsi.go.jp/ で住所検索）
   - 環境設定でネットワークポリシーの許可ドメインに `*.gsi.go.jp` を追加すれば自動化できること
2. 社長が目視確認した結果（浸水深・イエロー/レッド該当）を口頭で受け取った場合は、
   `--demo` を参考にスクリプトを使わずExcel表だけ作成してもよい（openpyxlで同形式）。
   その際は出典欄に「社長目視確認による」と明記する。

## 動作確認（ネット不要）

```bash
python3 .claude/skills/hazard-check/scripts/hazard_check.py --demo -o <scratchpad>/demo.xlsx
```

## 注意事項

- 本スキルはタイル画像の**色判定による自動評価**。指定区域の官報告示や自治体公表資料が正。
  売買・融資判断の前に必ず原本を目視確認すること（Excelにも注意書きを自動挿入済み）。
- ため池決壊・内水氾濫・液状化など上記以外のハザードは対象外。必要なら重ねるハザードマップで別途確認。
- ジオコーディングは住所表記の揺れに弱い。番地まで一致しない場合は結果の「ジオコーディング結果」欄を確認し、
  ズレがあれば社長に座標確認を求めること。
