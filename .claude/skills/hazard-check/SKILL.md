# ハザード確認スキル（クロコ / 物件調達課 標準ツール）

不動産投資の社内立地基準「ハザード非該当」（`CLAUDE.md` 判断指標）を検証するための標準手順。
WebFetch がブロックされる環境でも、Bash 経由の HTTP アクセスで動作する。

## 使い方

```bash
pip install -r scripts/requirements.txt   # requests / pillow が未インストールの場合のみ
python3 scripts/hazard_check.py "住所（例: 栃木県宇都宮市鐺山町2009-5）"
```

緯度経度が分かっている場合:

```bash
python3 scripts/hazard_check.py --latlon 36.537579 139.974533
```

## 何をしているか

1. 国土地理院 住所検索API（`msearch.gsi.go.jp/address-search/AddressSearch`）で住所→緯度経度に変換
2. 緯度経度から標準タイル座標(x, y, z)を計算
3. 「重ねるハザードマップ」の各レイヤー（洪水L1/L2・土砂災害3区分・津波・高潮・ため池・家屋倒壊等氾濫）のラスタタイル（`disaportaldata.gsi.go.jp/raster/.../{z}/{x}/{y}.png`）を取得
4. 物件地点に対応するピクセルの色を判定
   - 完全透明（alpha=0）→ 非該当
   - 色あり → 該当（洪水系は色から浸水深目安も判定）
   - タイル自体が404 → その周辺に指定区域データなし → 非該当

## 判定結果の使い方

- 全項目「非該当」→ 社内基準の立地要件を満たす
- いずれか「該当」→ 買付前に重要事項説明で正式な浸水深・区域区分を確認必須。火災保険の水災補償を検討。

## 既知の限界

- 国土地理院ジオコーダは地番の枝番（例: `2009-5` の `-5`）まで厳密に解決しない場合がある。境界線上の物件は公式サイト（重ねるハザードマップ／各市町村ハザードマップ）で最終確認すること。
- タイル画像の解像度上、ピンポイントでの厳密な境界判定には限界がある。
