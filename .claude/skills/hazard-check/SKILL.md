# ハザード確認スキル（重ねるハザードマップ座標照会）

住所から座標を求め、国交省「重ねるハザードマップ」の配信タイルデータをピクセル単位で照会して、
各ハザードの該当/非該当と最寄りハザード区域までの距離・方角を判定する。

## 手順A: スクリプト実行（コード実行＋外部ネットワークが使える環境）

```bash
python3 scripts/check_hazard.py "宇都宮市鐺山町2009"
```

- 引数は住所文字列（都道府県は省略可。番地の枝番はジオコーダーが解釈できないことがあるため、本番地までで照会し、その旨を報告に明記する）
- 依存: Pillow（未導入ならスクリプトが自動インストールを試みる）
- 出力: 各レイヤーの該当/非該当、最寄り区域の距離・方角・区分、標高、確認用URL

## 手順B: 手動照会（スクリプトやネットワークが使えない環境でのフォールバック）

1. 国土地理院ジオコーダーで住所→座標:
   `https://msearch.gsi.go.jp/address-search/AddressSearch?q=<URLエンコード住所>`
2. 重ねるハザードマップで地点を確認（ユーザーに開いてもらうリンクを提示）:
   `https://disaportal.gsi.go.jp/maps/?ll=<緯度>,<経度>&z=16`
3. Web検索・fetchで市町村公式ハザードマップ（例: 宇都宮市ハザードマップ）を補助確認する。

## 判定レイヤー（disaportaldata.gsi.go.jp 配信ラスタ）

| レイヤー | パス |
|---|---|
| 洪水浸水想定（想定最大規模L2） | `01_flood_l2_shinsuishin_data` |
| 洪水浸水想定（計画規模L1） | `01_flood_l1_shinsuishin_newlegend_data` |
| 浸水継続時間 | `01_flood_l2_keizoku_data` |
| 家屋倒壊等氾濫想定区域（氾濫流/河岸侵食） | `01_flood_l2_kaokutoukai_hanran_data` / `..._kagan_data` |
| 土砂災害警戒区域（土石流/急傾斜地/地すべり） | `05_dosekiryukeikaikuiki` / `05_kyukeishakeikaikuiki` / `05_jisuberikeikaikuiki` |
| 津波 / 高潮 | `04_tsunami_newlegend_data` / `03_hightide_l2_shinsuishin_data` |

タイルURL: `https://disaportaldata.gsi.go.jp/raster/<レイヤー>/{z}/{x}/{y}.png`（z=16基準）。
タイルが404＝そのタイル範囲（約600m四方）にデータ無し＝非該当。地点ピクセルが透明＝非該当。

## 報告フォーマット（社長向け・結論先出し）

1. **結論**: 全項目の該当/非該当を1行で（判断指標「ハザード非該当」の充足可否）
2. 表: ハザード種別 × 判定 × 周辺状況（最寄り距離・方角・浸水深区分）
3. 標高（国土地理院 標高API）と地形面の裏付け
4. 留意点: 枝番の位置ずれ・敷地形状ベースの最終確認（重説の水害リスク説明）を推奨
5. 根拠リンク: `https://disaportal.gsi.go.jp/maps/?ll=<緯度>,<経度>&z=16`
6. 社内規定に従い議事録を `docs/年月日_ハザード確認_<市区町村+町名+番地>.md` で保存（Claude Code環境の場合はコミット・プッシュ）
