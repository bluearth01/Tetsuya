# 買付証明書（不動産購入申込書）作成スキル

不動産の買付証明書を、決まったレイアウトの Word（.docx）で出力します。

## 出力書式（固定レイアウト）

1. 中央寄せタイトル「買 付 証 明 書」
2. 右寄せの作成日
3. 宛先（例：Ａ‐ＮＥＸＴ株式会社 御中／必要なら担当者名）
4. 買主（申込人）ブロック：住所／氏名＋㊞／連絡先（メール・TEL）
5. 本文「私は、下記不動産を…買付の意思表示をいたします。」＋「記」
6. 明細テーブル（物件名・所在地・物件種別・土地面積・建物面積・築年月・**購入希望価格（赤・太字）**・手付金・残代金・融資特約・引渡希望・有効期限）
   - 空欄の項目は自動でスキップ（例：残代金を空にすれば行ごと消える）
7. 【特記事項】（既定は白紙解約条項・意思表示の確認・売主直売の3点。`特記事項` 配列で上書き可）
8. 右寄せ「以 上」

## 使い方

1. 必要事項を `params.json` にまとめる（`params.sample.json` をコピーして編集）。
   - 金額・面積は資料の表記に合わせて全角で書くと体裁が整う（例：`金 ５３，１００，０００円`）。
     半角で渡して全角に揃えたいときは `"全角変換": true`（土地/建物面積・購入希望価格・手付金・残代金に適用）。
   - 不要な行は値を空文字 `""` にすれば出力されない。
   - `出力ファイル名` を指定（推奨パターン：`YYYYMMDD_買付証明書_<地名><価格>万.docx`）。
2. 依存をインストール（初回のみ。`node_modules` が無ければ）:
   ```bash
   cd .claude/skills/kaitsuke-shomei && npm install
   ```
3. 生成:
   ```bash
   node .claude/skills/kaitsuke-shomei/scripts/generate.js params.json "出力先.docx"
   ```
   （`出力先.docx` 省略時は params の `出力ファイル名` を使用）
4. 検証（任意）:
   ```bash
   python /mnt/skills/public/docx/scripts/office/validate.py "出力先.docx"
   ```

## パラメータ一覧（params.json）

| キー | 説明 | 例 |
|------|------|----|
| 作成日 | 右上の日付 | `2026年6月27日` |
| 宛先 | 売主/業者名＋御中 | `Ａ‐ＮＥＸＴ株式会社　御中` |
| 宛先担当 | 担当者行（任意） | `（ご担当：本間　様）` |
| 買主住所 | 申込人の住所 | `栃木県宇都宮市` |
| 買主氏名 | 申込人氏名（個人 or 法人＋代表者） | `黒岩 哲也` |
| 連絡先 | メール等 | `bluearth01@gmail.com` |
| TEL | 電話番号 | `080-4928-3803` |
| 物件名 / 所在地 / 物件種別 | 物件表示 | — |
| 土地面積 / 建物面積 / 築年月 | 物件明細 | — |
| 購入希望価格 | 赤太字で表示 | `金 ５３，１００，０００円` |
| 手付金 / 残代金 | 任意（空なら非表示） | `金 １，０００，０００円` |
| 融資特約 | ローン特約 | `有（ローン利用）` |
| 引渡希望 / 有効期限 | 条件 | — |
| 特記事項 | 文字列配列（任意・既定3点を上書き） | `[]` |
| 全角変換 | 金額/面積を全角化 | `false` |
| 出力ファイル名 | 既定の出力名 | `20260627_買付証明書_….docx` |

## 完了後に提示するもの

生成後、次を必ずユーザーに返す:
- 生成ファイル（.docx）
- 「記載内容サマリー」表（作成日・有効期限・所在地・物件種別・購入希望価格・手付金・残代金・融資特約・買主）
- 「要確認事項（修正が必要な箇所）」
  - 買主名義（個人／法人）が融資の名義と一致しているか
  - 宛先（売主直売か仲介経由か。仲介なら業者名）
  - 構造・戸数・面積が物件概要書と一致しているか
  - 手付金額・有効期限・融資承認取得期限

## 注意

- 値の数値はそのまま転記する。**売買契約書の価格と買付価格は実額で一致**させること（水増し記載はしない）。
- フォントは Yu Mincho 指定（環境に無ければ Word が代替）。
